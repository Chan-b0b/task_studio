1 · 블록의 정의

블록은 파이썬 클래스 하나. 종류는 동작과 조건 둘뿐

# task_studio/core/skill.py
class Result(BaseModel):
    status: Literal["ok", "fail", "aborted"]
    reason: str = ""                      # 실패 이유 어휘는 스킬마다 고정

class ActionResult(Result):              # 모든 동작의 출력이 상속
    stopped_by: str                       # reached / <가드> / unreachable / aborted
    pose_at_stop: Pose | None = None

class Skill:                              # 동작(Action)
    name: ClassVar[str]
    Input: ClassVar[type[BaseModel]]      # pydantic 모델 = 입력 포트
    Output: ClassVar[type[Result]]        # pydantic 모델 = 출력 포트
    requires: ClassVar[frozenset[str]]    # {"left_arm", "suction"} 병렬 충돌 검사
    def run(self, ctx: Context, inp: BaseModel) -> Result: ...   # 블로킹

class Condition:                          # 조건
    name: ClassVar[str]
    Input: ClassVar[type[BaseModel]]
    def check(self, ctx: Context, inp: BaseModel) -> bool: ...   # 즉시
동작조건
실행run() 끝날 때까지 블로킹check() 지금 상태를 보고 즉시
출력ActionResult + 스킬별 필드bool
꽂히는 곳트리의 잎동작의 guards, 또는 Condition 노드
스킬은 트리를 모른다. run()은 그냥 함수다. 엮는 방식이 바뀌어도 스킬은 그대로.
실패는 예외가 아니라 Result.reason. 어떻게 복구할지는 트리가 정한다.
입·출력이 pydantic이라 스키마가 곧 포트다. 편집기 툴박스와 타입 검사가 여기서 나온다.
2 · 동작의 공통 계약

모든 동작은 guards·timeout을 받고 stopped_by를 돌려준다

# 긴 동작의 뼈대. 모든 동작이 이 모양이다.
def run(self, ctx, inp):
    arm = ctx.robot.arm
    arm.start_line(inp.pose, inp.speed)          # 하드웨어에 명령
    t0 = now()
    while not arm.done():
        ctx.check()                              # 일시정지 / E-stop / 힘 한계 → Aborted 예외
        for g in inp.guards:                    # 가드: 매 tick 묻는다
            if g.check(ctx):
                arm.stop()
                return ActionResult(status="ok", stopped_by=g.name,
                                    pose_at_stop=arm.pose())
        if now() - t0 > inp.timeout:
            arm.stop()
            return ActionResult(status="fail", reason="timeout",
                                stopped_by="timeout")
        sleep(TICK)
    return ActionResult(status="ok", stopped_by="reached",
                        pose_at_stop=arm.pose())
stopped_by뜻status
reached목표에 도달ok
<가드 이름>가드가 울려 멈춤. 예: ForceOver = 접촉ok
unreachableIK 해 없음, 관절 한계fail
timeout시간 초과fail
abortedctx.check()가 예외를 던짐aborted
가드가 울리는 건 실패가 아니다. "창에 들어올 때까지 기어가라"는 BaseMove + BEVInWindow 가드이고, 가드가 울리면 성공이다.
ctx.check()와 가드는 다르다. 전자는 운영자·안전(선점), 후자는 그 동작을 멈추는 조건. 결과도 aborted vs stopped_by로 다르다.

숫자(오프셋·높이·힘·속도)는 전부 입력 필드. 기본값은 params.yaml, 프로그램이 주면 그 값이 이긴다. 기존 동작 + 조건으로 적을 수 있으면 새 블록을 만들지 않는다.

동작 하나 25줄, 조건 하나 10줄

# task_studio/skills/motion/move_ee.py
class MoveEE(Skill):
    name = "MoveEE"
    requires = frozenset({"left_arm"})

    # guards, timeout 은 ActionInput 에서 상속
    class Input(ActionInput):
        pose: Pose
        straight: bool = True       # 직선, 아니면 관절 공간 호
        keep_xy: bool = False       # 수직 전용
        speed: float = param("arm.speed")   # params.yaml

    class Output(ActionResult):
        error_m: float = 0.0

    def run(self, ctx, inp):
        arm = ctx.robot.arm
        if not arm.reachable(inp.pose):
            return self.Output(status="fail",
                reason="unreachable", stopped_by="unreachable")
        arm.start(inp.pose, straight=inp.straight,
                  keep_xy=inp.keep_xy, speed=inp.speed)
        # 앞 장의 루프: ctx.check + 가드 + timeout
        r = guarded_wait(ctx, inp, done=arm.done, stop=arm.stop)
        ctx.emit("move_ee_end", stopped_by=r.stopped_by)
        return self.Output(**r.dict(),
                           error_m=arm.error_to(inp.pose))
# task_studio/skills/conditions/force_over.py
class ForceOver(Condition):
    name = "ForceOver"

    class Input(BaseModel):
        axis: Literal["x", "y", "z"] = "z"
        threshold_n: float = 10.0
        relative: bool = True          # 이동 중앙값 대비 변화량
        window_s: float = 0.25

    def check(self, ctx, inp) -> bool:
        f = ctx.robot.wrist.force(inp.axis,
                                  window=inp.window_s)
        v = f.delta if inp.relative else f.now
        return v > inp.threshold_n

등록과 노출

  • Skill 상속 = 레지스트리 등록. import 되면 끝.
  • 로더는 MoveEE: {…}를 레지스트리에서 찾아 Input(**args)로 검증. 틀린 필드는 로드 시점에 터진다.
  • 툴박스·포트 타입은 Input.model_json_schema()에서 자동.
  • 하드웨어는 ctx.robot.* 인터페이스로만. dexcontrol은 vega/ 안에만.

6 · 잇는 법

선 세 종류, 노드 여덟 개

선뜻YAML
순서선부모 노드가 자식을 어떤 순서·정책으로 돌리나노드 아래 들여쓴 목록
값선한 블록의 출력이 다른 블록의 입력으로. 블랙보드의 $변수out: $det → det: $det
가드선동작이 도는 동안 조건을 계속 본다guards: [ForceOver: {…}]
실패 처리는 블록 안이 아니라 트리 모양에 있다. 블록이 fail을 돌려주면 Sequence가 멈추고, 위의 Fallback이 다음 자식(재검출, 또는 Gate)을 시도한다.
식은 산술·비교·논리만 ($stack.src - 1). 과제 지식이 드는 계산은 식이 아니라 블록이다. 그래야 YAML과 그래프가 1:1.
프로그램 파일 = main 트리 + on_abort 트리. 어디서 멈추든 on_abort가 돈다.
노드뜻지금 코드에서는
Sequence차례로, 하나 실패하면 실패함수 본문
Fallback차례로, 하나 성공하면 성공재검출 → 안 되면 운영자
Retry(n)실패하면 n번 다시MAX_PHASE_ATTEMPTS
Parallel(policy)동시에. 전부 / 하나 끝나면. requires 겹치면 로드 시 거절_park_during_legs
Loop(while)반복, 블랙보드 값으로 종료while src ≥ 1
Condition조건 블록 또는 식을 한 번 검사if descent_reachable()
Gate(prompt, allowed)운영자 결정까지 멈춤. autonomy 레벨로 자동 통과 가능input("Continue?")
Set블랙보드 값 바꾸기src -= 1

8 · 과제 층이 블록을 더하는 법

원자 블록을 더하거나, 묶어서 복합 블록을 만든다

# tasks/lges/manip/suction_pick.py  — 복합 스킬도 같은 Skill 계약
class SuctionPick(Skill):
    name = "SuctionPick"
    requires = frozenset({"left_arm", "suction"})

    class Input(ActionInput):
        pose: Pose
        expected_z: float
        approach_above: float = param("pick.approach_above")

    class Output(PickResult): ...

    def run(self, ctx, inp):
        above = OffsetPose.call(ctx, pose=inp.pose, dz=inp.approach_above)
        MoveEE.call(ctx, pose=above)                        # 위로
        r = MoveEE.call(ctx, pose=inp.pose, straight=True, keep_xy=True,
                        guards=[ForceOver(),                # 접근: 접촉까지
                                SafetyFloor(z_min=inp.expected_z - 0.03),
                                *inp.guards])
        if r.stopped_by != "ForceOver":
            return self.Output(status="fail", reason="no_contact", **r.dict())
        SuctionOn.call(ctx)
        w = Wait.call(ctx, timeout=1.0, guards=[Sealed()])  # 씰 될 때까지
        MoveEE.call(ctx, pose=above)                        # 들기
        return self.Output(status="ok", stopped_by=r.stopped_by,
                           contact_z=r.pose_at_stop.z,
                           sealed=(w.stopped_by == "Sealed"))
